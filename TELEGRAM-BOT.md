# Заявки з сайту в Telegram

Обидві форми сайту («Залиште заявку» і бічна панель у шапці) надсилають заявку
на `/api/lead` (`src/app/api/lead/route.ts`), а сервер пересилає її боту в Telegram.

## Налаштування (один раз)

1. У Telegram відкрийте **@BotFather** → `/newbot` → задайте назву та username.
   BotFather видасть **токен** виду `1234567890:AA...`. Нікому його не показуйте.
2. Куди слати заявки:
   - **собі особисто** — відкрийте свого бота й натисніть «Start»;
   - **у групу для кількох людей** — створіть групу, додайте туди бота і напишіть у групі будь-що.
3. Дізнайтесь id чату:
   ```
   node scripts/telegram-chat-id.mjs <ТОКЕН>
   ```
   Скрипт надішле тестове повідомлення і покаже рядок `TELEGRAM_CHAT_ID=...`.
4. Локально: створіть у корені проєкту файл `.env.local`:
   ```
   TELEGRAM_BOT_TOKEN=1234567890:AA...
   TELEGRAM_CHAT_ID=123456789
   ```
   (кілька отримувачів — через кому) і перезапустіть `npm run dev`.
5. На Vercel: Project → Settings → Environment Variables → додайте ті самі дві змінні
   для Production → зробіть Redeploy.

## Що приходить

Напрямок, ім'я, телефон у форматі `+380XXXXXXXXX`, текст задачі, сторінка сайту, пристрій (телефон / планшет / комп'ютер, система, браузер), з якої форми, час за Києвом.

## Захист

- сервер повторно перевіряє поля;
- приховане поле-пастка відсіює ботів;
- не більше 5 заявок з однієї IP-адреси за 10 хвилин.
